## II-B-3

[[Shifting]] phase means that both parties discard some symbols 

basically here are discarded the bits whose bases mismatched. 


after [[Parameter estimation]] and [[Shifting]], Alice and Bob have a list of n<=N  symbols ([[raw key]])

after post-processing these n symbols can be transformed into a fully secure key of length K ( with length l <= n )
